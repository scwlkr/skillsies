# Bubba’s public design entry point

Load the installed `bubba-design` skill before doing this work. Its maintained
source is `handh-dev/bubbas-brand-studio/skills/bubba-design/SKILL.md`, installed
for Codex, Cursor and Claude. Resolve its real path and read the requesting
repository’s current design-system pin and instructions.

Use that workflow to find an existing shared solution, reuse or extend its
owning source, integrate the requesting app, and update shared examples and
contracts. Public experiences carry Bubba’s expressive identity; the maintained
system defines current typography, appearance, composition and accessibility.
Use approved original assets with their actual distribution rights and retain
source/version/checksum provenance. Core remains the owner of business facts.

This compatibility skill retains the existing invocation name. Earlier palette,
fixed page-layout and gradient rules are historical Git provenance; they are
superseded by Brand Studio’s current foundations and reviewed consumer pins.
Do not create a second palette or infer an artwork approval from this routing.

If the installed skill is missing, locate the maintained source above and use
its installation instructions. Preserve unrelated agent configuration and fail
clearly if the authority or required pin cannot be resolved.
